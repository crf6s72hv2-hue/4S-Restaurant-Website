# 4S Restaurant & Café Website

Premium luxury website for 4S Restaurant & Café in Duhok, Iraq.

## Features

- **Bilingual (English / Arabic)** with full RTL layout support
- **Complete digital menu** — 25 categories, 169 items with real photos and prices (sourced from the official mynu.app API)
- **Dedicated Hookah section** with all 10 shisha flavors
- **Gallery** with full-screen lightbox (keyboard navigable)
- **Featured dishes**, customer reviews carousel, reservation form
- **Google Maps** integration for location
- **Floating WhatsApp & Call buttons**
- **SEO optimized** with Open Graph, Twitter cards, and JSON-LD structured data
- **Premium design** — glassmorphism, smooth animations, luxury typography
- **Mobile-first responsive** design

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- lucide-react icons

## Getting Started

```bash
npm install
npm run dev
```

## Building

```bash
npm run build
npm run typecheck
```

## Menu Data Source

The menu data is sourced from the official 4S mynu.app API and stored in `src/data/menuData.ts`. All 169 items include bilingual names (EN/AR), prices in IQD, and real product images.
